# ArrowNexa Play Store Prep

## Short Description Draft
Tap arrows, find open paths, and clear elegant logic puzzles from Easy to Expert.

## Full Description Draft
ArrowNexa is a clean arrow puzzle game about finding the way out.

Tap arrows that have a clear path, remove them from the board, and untangle increasingly dense puzzles. Start with simple layouts, then work through harder boards with layered paths, daily challenges, achievements, stars, XP, boosters, and offline progression.

Features:
- Simple tap-to-clear arrow puzzle gameplay
- Hundreds of handcrafted-feeling generated levels
- Easy, Normal, Hard, and Expert difficulty progression
- Daily Challenge and Weekly Goals
- Achievements, statistics, stars, XP, and Nexa Rank
- Hints, undo, lives, and optional boosters
- Clean visual style designed for focused play
- Offline gameplay for core puzzle features
